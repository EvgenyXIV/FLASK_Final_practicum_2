# Flask-Приложение "Личный Дневник" — Полное описание

## Общее описание

**Личный дневник** — это полноценное веб-приложение на Flask, реализующее систему ведения записей с аутентификацией пользователей, сессиями и полным циклом CRUD-операций. Проект включает

- бэкенд,
- базу данных,
- адаптивный фронтенд с Jinja2-шаблонами и CSS-стилями.

---

## 🔧 Основные функции

- ✅ **Регистрация и авторизация пользователей**
  - `/register` — форма регистрации (логин, email, пароль)
  - `/login` — вход в систему
  - `/logout` — выход из аккаунта
- 🔐 **Сессии и защита маршрутов**
  - Используется временная сессия (30 минут) через токен
  - Все действия доступны только авторизованным пользователям
- 📝 **Управление записями (CRUD)**
  - Создание (`/form_create`)
  - Просмотр всех записей
  - Редактирование по ID
  - Удаление по ID
- 🗂️ **База данных SQLite**
  - Таблицы: `Card` (записи дневника), `Users` (пользователи)
  - Миграции через Flask-Migrate

---

## 🖼️ Фронтенд и пользовательский интерфейс

### Шаблоны (Jinja2)

Проект использует **наследование шаблонов**, где `index.html` — базовый шаблон, а остальные его расширяют.

| Шаблон | Назначение |
|--------|-----------|
| `index.html` | Главная страница с меню, формами и выводом записей |
| `home.html` | Стартовая страница с навигацией (регистрация, вход, выход) |
| `login.html` | Форма входа |
| `register.html` | Форма регистрации |
| `card.html` | Интерфейс управления записями (просмотр, редактирование, удаление) |
| `form_create.html` | Форма создания новой записи |

### Особенности интерфейса

- 🖱️ **Навигация через иконки**  
  Все переходы реализованы через кликабельные изображения (`png`) — интуитивно понятный UI.
- 💬 **Flash-сообщения**  
  Поддержка уведомлений (ошибках входа, успешной регистрации и т.д.) через `get_flashed_messages()`.
- 📱 **Адаптивность**  
  Используется `<meta name="viewport">`, шаблоны центрированы, контент не "расползается".

### Визуальные элементы

- Логотип Synergy в верхнем левом углу
- Иконки для действий:
  - `main_page.png` — главная
  - `register.png` — регистрация
  - `login.png` — вход
  - `logout.png` — выход
  - `card_new.png` — новая запись
  - `card_all.png` — просмотр всех
  - `card_change.png`, `card_del.png` — редактирование и удаление

## 🔐 Безопасность (замечания)

- ⚠️ **Пароли хранятся в открытом виде** — нужно использовать `generate_password_hash()` и `check_password_hash()`
- 🔒 Сессии защищены временными метками, но лучше использовать `flask-login` полностью (вместо ручного управления токеном)
- 🧩 `config['LOGIN_DISABLED'] = True` — отключена встроенная система Flask-Login, используется кастомная проверка
